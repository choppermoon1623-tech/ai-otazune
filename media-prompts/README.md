# メディア生成用プロンプト

Gemini CLIがここにプロンプトを書き、人間がGeminiアプリ／Flowで手動生成します。
生成済み素材は `assets/generated/` に保存します。CLIから生成APIを呼び出しません。

案件ごとに `YYYY-MM-DD-用途.md` を作成し、次のテンプレートを埋めてください。
生成ツールと契約内で利用できる機能は、人間が生成前に確認します。
